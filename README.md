# Migration Files — The Scouse Oracle

A sourced guide to UK migration and asylum data. Public beta: selected, manually reviewed evidence, not a live feed or complete national database.

## Website

GitHub Pages is configured from the main branch, repository root. Use the deployment URL shown in repository Settings → Pages.

## Corrections

[Report a correction](https://github.com/TheScouseOracle/migration-files/issues/new?template=correction.md). GitHub reports are public and require a GitHub account. Do not include personal immigration records or accommodation addresses. The website Updates & Corrections page explains review limits and records material changes.

## Source and downloads

The site runs directly from index.html with no build step. data/ contains dated exports; downloads/ contains the aggregate database schema and migrations 001–006. These are downloadable migrations, not a live hosted database. Original publishers retain their source licences and exceptions.

## Beta review — 22 September 2026

Four data validation suites passed before transfer. The 44 distinct source URLs in the data exports were reachable and all 12 download routes responded successfully. Search, filtering, evidence panels, keyboard tabs and desktop/narrow-phone layouts were checked. These checks do not constitute a full independent audit of every claim in every registered publication.
